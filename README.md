# Kalyan Jewellers – Financial Performance Dashboard (FY2017–FY2025)

An Excel-based financial performance dashboard built from Kalyan Jewellers' audited Annual Reports, covering FY2017 to FY2025. The workbook consolidates the company's Statement of Profit and Loss, Statement of Financial Position, and Statement of Cash Flows into a single interactive dashboard for analysing profitability, returns, working capital, liquidity, solvency, and cash flow trends.

## Objective

The dashboard was built to:

- Present historical financial performance in a structured, interactive format
- Evaluate operational performance using profitability and efficiency metrics
- Measure capital utilisation through return ratios
- Analyse working capital management and liquidity efficiency
- Track growth using Year-on-Year (YoY) and CAGR analysis
- Allow year-wise comparison across FY2017–FY2025 with minimal manual effort

All figures are based on historical, audited financial statements only. No forecasts or forward-looking assumptions are included.

---

## Key Metrics Covered

**Profitability & Earnings**
Revenue, Gross Profit, EBITDA, EBIT, EBT, PAT, EPS (Basic), and associated margins

**Return Ratios**
- ROCE = EBIT ÷ (Total Assets − Current Liabilities)
- ROE = EBT ÷ Total Equity

**Working Capital**
- Working Capital Cycle = Inventory Days + Receivable Days − Payable Days

**Liquidity & Solvency**
- Current Ratio = Current Assets ÷ Current Liabilities
- Quick Ratio = (Current Assets − Inventories) ÷ Current Liabilities
- Gearing Ratio = (Non-Current Borrowings + Non-Current Lease Liabilities) ÷ Equity
- Interest Cover = EBIT ÷ Finance Cost

**Cash Flow**
Cash Flow from Operating, Investing, and Financing activities (CFO, CFI, CFF)

**Growth Analysis**
- YoY Growth (%) = [(Current Year − Previous Year) ÷ Previous Year] × 100
- 5-Year CAGR = (FY2025 Value ÷ FY2020 Value)^(1/5) − 1
- 3-Year CAGR = (FY2025 Value ÷ FY2022 Value)^(1/3) − 1

## Design Approach

- Single-page executive dashboard for quick, high-level review
- Interactive slicers for year-wise filtering
- Consistent colour coding to distinguish positive and negative trends
- Minimal decorative elements, prioritising clarity over visual noise
